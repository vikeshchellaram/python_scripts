# Python for Financial Markets, Data Analytics & Automation

A collection of practical Python scripts developed to support **financial markets, data analytics, business process automation, and integration with enterprise systems**.

The repository reflects practical applications of Python to automate repetitive workflows, process financial data, interact with business applications and support operational activities.

## Key Areas

- Financial market data and economic analysis
- Data processing and visualisation
- Process automation
- Enterprise system integration
- API interactions
- Financial data retrieval
- Workflow and operational automation

## Technologies

- **Python**
- **pandas / NumPy**
- **Matplotlib / Seaborn**
- **FRED API**
- **Prophet**
- **SQL / Oracle**
- **REST APIs**
- **Jira**
- **Refinitiv Eikon**
- **Microsoft Outlook**
- **PyAutoGUI**
- **Windows COM automation**

## Projects

### `functions.py`

A collection of reusable functions for data analysis and financial workflows.

Includes:

- Data loading and processing with pandas
- Data visualisation
- Statistical analysis
- FRED economic and financial data retrieval
- Time-series forecasting using Prophet
- Oracle database connectivity and SQL query execution
- Logging and configuration utilities

### `jira_connection.py`

Python integration with **Jira REST APIs**.

The script demonstrates how Python can be used to:

- Authenticate with Jira
- Retrieve Jira issues through REST APIs
- Create and update tickets
- Process JSON payloads
- Automate interactions with enterprise workflow systems

### `reuters.py`

Automation of the **Refinitiv Eikon** desktop application.

The script demonstrates:

- Launching the Eikon application
- Detecting and interacting with the application window
- Automating user-interface interactions with PyAutoGUI
- Reading credentials from configuration files
- Automating repetitive login workflows

### `emails_archiving.py`

Automation of an email archiving workflow using **Microsoft Outlook and Python**.

The script handles:

- Outlook mailbox and folder navigation
- Filtering emails by date
- Creating local archive structures
- Saving emails as `.msg` files
- Creating corresponding archive folders
- Uploading archived documents
- Deleting successfully archived emails
- Processing multiple accounts and nested folders

The script is designed to reduce manual operational work and support repeatable email-archiving processes.

### `passwordgen.py`

A lightweight utility for generating random passwords using Python's standard library.

## Why This Repository?

These projects demonstrate how Python can be applied beyond pure software development to solve **business and operational problems**.

The focus is on using technology to:

**Analyse data → Automate processes → Integrate systems → Reduce manual work → Improve operational efficiency**

The projects are developed from a financial markets and business analysis perspective, combining knowledge of **capital markets, financial systems, data analytics and process automation**.
